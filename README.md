# Phone Sale Website

This is a **MERN stack full-stack project** designed to facilitate the buying and selling of new or used phones. Users can list their phones for sale, and admins are responsible for verifying and validating the listings. 

---

## Features

### User Features:
- **Sign Up / Log In**: Users must create an account to use the platform.
- **Sell Phones**: Users can list their new or used phones for sale.
- **Manage Listings**: Users can remove their listed phones.

### Admin Features:
- **Verify Listings**: Admins validate user-submitted phone listings to ensure authenticity.
- **Remove Listings**: Admins can remove any inappropriate or invalid phone listings.

---

## Tech Stack

### Frontend:
- **React.js**: User interface development.
- **Tailwind CSS / MUI / Bootstrap**: For styling the website.

### Backend:
- **Node.js**: Server-side runtime environment.
- **Express.js**: Web framework for API development.

### Database:
- **MongoDB**: Database for storing user, phone, and listing information.

### Tools:
- **JWT**: Authentication and authorization.
- **Postman**: For testing APIs.
- **Git & GitHub**: Version control.
